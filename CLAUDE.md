# Nixi — ghi chú cho Claude

App remote all-in-one kiểu MobaXterm (tên cũ: **EZTERM**, đổi thành **Nixi** ngày 2026-10-28), mục tiêu chính là **macOS** (Electron 33 + TypeScript + React 18).
Tác giả / chủ dự án: Thao Pham · thaopham.cyber@gmail.com.

## Làm việc với chủ dự án
- Trả lời bằng **tiếng Việt**, xưng "tao / mày" như chủ dự án dùng. Ngắn gọn, nói rõ cái gì đã kiểm tra, cái gì chưa.
- Sửa xong thì **chạy test liên quan + typecheck** rồi mới báo xong; lỗi giao diện thì tái hiện bằng script e2e (Playwright) và chụp màn hình trước khi sửa.
- Project được phát triển trên Windows tới 2026-10-28, sau đó **chuyển sang Mac** để làm tiếp. Lịch sử chat cũ không còn — file này là phần bàn giao.

## Lệnh
```bash
npm ci                    # cài (npm 11: nếu bị chặn install script → npm install-scripts approve electron esbuild ssh2)
npm run dev               # chạy dev (electron-vite)
npm test                  # unit test (vitest, tests/*.test.ts) — không cần Electron
npm run typecheck         # tsc --noEmit
npm run build             # build vào out/ (e2e chạy trên bản build này)
npm run dist:mac          # .dmg cho kiến trúc của máy đang build (chỉ build được trên macOS)
npm run dist:mac:arm64    # .dmg cho Mac chip M (~66 MB) — build được cả trên máy Intel
npm run dist:mac:x64      # .dmg cho Mac Intel (~75 MB)
npm run dist:win          # .exe NSIS
node scripts/dev-ssh-server.mjs [--port 2222] [--auth-delay 1500]   # SSH server giả (test/test): PTY, SFTP, -L/-R/-D
```
E2E (`scripts/e2e-*.mjs`, Playwright `_electron`) chạy trên `out/` với profile tạm: env `NIXI_USER_DATA=<thư mục tạm>` + `NIXI_TEST_PASSWORD=<pw>` để app tự tạo/mở database và chuyển các file JSON kiểu cũ có trong profile vào. Xoá profile tạm sau khi chạy.

## Kiến trúc
```
src/shared/     types, parse (ssh_config, cây folder — có cả folder rỗng), macro (định dạng text), mobaxterm (ini ⇄ session), about
src/main/       index (window, menu, single-instance, khoá DB), ipc (mọi handler trả {ok,value|error}; preload unwrap)
  conn/manager  terminal: local (node-pty @lydell/node-pty), SSH shell (ssh2), Telnet
  ssh/          connect (auth, jump host, agent), sftp, tunnels (-L/-R/-D, SOCKS5 tự viết), socks
  telnet/       protocol (IAC, ECHO/SGA/TTYPE/NAWS, CR LF) + AutoLogin
  rdp/          proxy (main) + proxy-worker (utilityProcess): WebSocket ⇄ TCP+TLS theo RDCleanPath; rdcleanpath (DER); rdp-file (.rdp cho client native)
  store/        database (1 file .ezdb mã hoá), db-crypto (thuần, có unit test), stores/secrets/known-hosts (DbStore), legacy (migrate JSON cũ)
  import/       mobaxterm (pick/import/export), moba-crypto (giải mã macro bằng master password MobaXterm)
src/preload/    contextBridge `window.api` (typed, renderer import type từ đây)
src/renderer/   React + zustand (store.ts), terminals.ts (xterm registry), rdp.ts (IronRDP ngoài React), actions.ts (lệnh menu)
```
- Renderer sandbox + contextIsolation; mọi kết nối mạng ở main. CSP trong `src/renderer/index.html` (có `wasm-unsafe-eval`, `ws://127.0.0.1:*`).
- Phím tắt: trên mac dùng ⌘; Windows/Linux đổi sang Ctrl+Shift / Ctrl+Alt+Shift (hàm `accel` trong main/index.ts) để không chiếm Ctrl+R/D của shell.

## Các quyết định / bài học quan trọng (đừng làm hỏng lại)
- **Đổi tên EZTERM → Nixi**: thư mục dữ liệu đổi thành `…/Application Support/Nixi`, file `nixi.local.json`, database mặc định `nixi.nxdb` (hộp mở file vẫn nhận `.ezdb`). Lần chạy đầu `migrateFromEzterm()` (store/legacy.ts) chép `ezterm.local.json` sang (giữ đường dẫn database, kể cả file đặt chỗ khác) hoặc copy `ezterm.ezdb` mặc định; thư mục cũ để nguyên. Khoá "remember" gắn với tên app trong Keychain nên có thể phải nhập master password 1 lần. **Định danh định dạng `ezterm-db` trong file giữ nguyên** (nằm trong AAD — đổi là không mở được database cũ). Env test: `NIXI_USER_DATA`, `NIXI_TEST_PASSWORD`.
- Quick connect đã bị bỏ hẳn (ô nhập toolbar, menu ⌘L, nút ở màn hình chào, `parseQuickConnect`, `OpenConnRequest.quick`) theo yêu cầu chủ dự án.
- Thư mục session: ngoài thư mục suy ra từ `session.folder`, DB có `folders: string[]` cho thư mục rỗng (`buildTree(items, folders)`); đổi tên / ungroup / xoá folder phải sửa cả danh sách này. Chuột phải vùng trống của cây, session hay folder đều có "New session… / New folder…".
- **Database** (`store/database.ts`): một file `nixi.nxdb` kiểu KeePass. AES-256-GCM, khoá scrypt (N=2^17, r=8) từ master password; header (format/version/kdf) là AAD. Ghi atomic + `.bak`. "Remember on this computer" = lưu khoá dẫn xuất qua `safeStorage` trong `nixi.local.json` (không nằm trong DB). Lock → main gọi `webContents.reload()` (renderer không tự reload được vì `will-navigate` bị chặn).
- **Lỗi chữ vỡ**: xterm WebGL dùng chung texture atlas giữa các terminal → mở/đóng terminal làm vỡ chữ của terminal khác. Đã xử lý bằng `repaintAll()` (clearTextureAtlas + refresh) khi tạo/đóng terminal, khi tab/pane hiện lại, khi focus cửa sổ, khi đổi DPR. Setting `gpuRendering` để tắt WebGL.
- **Kích thước terminal**: sau khi kết nối xong luôn gửi lại cols/rows (resize lúc đang kết nối bị bỏ) — thiếu là con trỏ lệch/ghi đè.
- **Mật khẩu**: prompt xếp hàng (`promptQueue` trong store.ts), nhớ mật khẩu đã gõ trong RAM theo session, sai thì hỏi lại tối đa 3 lần. ssh2 có thể emit nhiều `error` → luôn có listener (nếu không main process crash). Chỉ dùng ssh-agent khi socket thật sự tồn tại.
- **RDP nhúng**: `@devolutions/iron-remote-desktop` (+ `-rdp`, WASM ~6 MB, lazy load). Proxy RDCleanPath tự viết chạy trong utilityProcess; ticket 1 lần để không thành open relay; chứng chỉ RDP kiểm tra kiểu TOFU. BoringSSL từ chối cert tự ký của Windows (`KEY_USAGE_BIT_INCORRECT`) → thử lại với TLS 1.2 + RSA key exchange. IronRDP chỉ có RemoteFX/bitmap (giải mã CPU) nên không mượt bằng client chính chủ → mỗi session có `rdpClient: 'native'` để mở Windows App / mstsc.
- **Split view**: pane sống ngoài React (xterm element / RDP element được di chuyển DOM, không tạo lại) → di chuyển pane không mất kết nối. Tên tab không tự đổi khi ghép.
- **MobaXterm**: format theo gist Ruzgfpegk (.mxtsessions). SSH (#109 type 0), RDP (#91 type 4), Telnet (type 1, chỉ host/port). Macro của chủ dự án bị mã hoá `em:/_@…` bằng master password MobaXterm — bộ giải mã thử nhiều biến thể (chưa kiểm chứng với dữ liệu thật). Export Telnet/local bị bỏ qua.
- Server stats (`shared/stats.ts` + `watchStats` trong conn/manager.ts + `StatsBar.tsx`): renderer mở/tắt theo vòng đời thanh; main chạy `sh -s` trên **kênh exec riêng** của chính kết nối SSH và ghi `STATS_SCRIPT` vào stdin (không phụ thuộc login shell là fish/csh), script in khối `key values` mỗi 3s kết thúc bằng `--`. CPU/mạng tính từ 2 khối liên tiếp. Dòng `fs …` = từng dòng `df -Pkl`; `parseDf` lọc ổ ảo (tmpfs, snap, /System/Volumes/* trừ Data…) → bảng hiện khi hover Disk (popup `position: fixed`, tự đo rộng để không tràn). Server không chạy được (Windows OpenSSH, exec bị cấm) → `null` → ẩn thanh. Dev SSH server đã hỗ trợ `exec`.
- Tunnel UI (`TunnelManager.tsx`): sơ đồ 3 khối theo chiều dữ liệu đi; -R đặt SSH server bên trái (nó là nơi lắng nghe). Mũi tên xanh = đoạn SSH mã hoá.
- Icon: `components/Icons.tsx` — SVG 2D tự vẽ (folder vàng mở/đóng, ô màu theo loại session, icon nét cho toolbar). Đừng quay lại emoji: font hệ thống vẽ `⌨` thành vạch, kích thước lệch nhau.
- Bố cục co giãn bằng **container query** (`container-type: inline-size` trên `.toolbar` và từng `.stats-bar`): toolbar < 820px chỉ còn icon; thanh stats bỏ dần users/uptime → load/host → mạng → thanh vạch (chỉ còn %). Theo chiều rộng của chính thanh, nên pane chia nhỏ cũng tự gọn.
- Full screen (macOS): main gửi `window:fullscreen` → class `fullscreen` trên `<html>`: bỏ khoảng 80px chừa nút đèn (Session/Local dịch sát trái) và tắt `-webkit-app-region: drag` (vùng kéo trong full screen là nguồn lỗi click bị kẹt đã biết). Chủ dự án báo **app treo khi full screen** nhưng chưa tái hiện được (setFullScreen bằng code với SSH + split + stats đều không treo) → main ghi `unresponsive` / `render-process-gone` vào `<userData>/nixi.log` để lần sau có dữ liệu.
- **SFTP transfer** (`main/ssh/sftp.ts`): mỗi lần up/down (nhiều file + folder) là **một** `Transfer` (bytes tổng, `files`/`filesDone`, `current`). Download (chuột phải → Download…, nút toolbar) luôn hỏi thư mục: `sftp:pickDownloadDir` mở hộp chọn folder tại `settings.downloadDir`, Cancel = không tải. Trước khi chạy renderer gọi `sftp:conflicts` (tên cấp trên cùng đã có ở đích) → `askChoice` (Cancel / Overwrite / Keep both); Keep both = `withRandomSuffix` (shared/parse: `report-48213.pdf`, `logs-48213.tar.gz`, folder/dotfile thêm ở cuối), thử lại nếu vẫn trùng. Kéo-thả: file từ Finder thả vào panel (hoặc lên **dòng folder** để up vào folder đó). Kéo dòng ra ngoài = `sftp:dragOut`:
  - **macOS: file promise** — module native `native/drag-promise.mm` (N-API, Obj-C++, `NSFilePromiseProvider`; `scripts/build-native.mjs` build universal x86_64+arm64 vào `native/out/nixi_drag.node`, chạy tự động trong `npm run build/dev`, đóng gói qua `mac.extraResources`; loader `main/ssh/drag-promise.ts`). Drag bắt đầu ngay, chưa tải gì; khi thả, Finder gọi `writePromiseToURL` với đường dẫn đích của từng mục → gom các mục của cùng lần thả (80 ms) thành một lô `download(..., 'rename', as)` vào đúng thư mục thả, xong gọi `complete`. Lý do: cách cũ (tải về temp rồi `startDrag`) làm folder/file lớn rơi vào thư mục Download vì người dùng nhả chuột trước khi tải xong.
  - Không có module (Windows/Linux, hoặc build native lỗi): cách cũ — tải về `tmp/nixi-drag/<uuid>` rồi `webContents.startDrag`; nhả chuột trước khi tải xong (`sftp:dragReleased`) thì chép vào thư mục download và báo. Thả lại file trong `nixi-drag` vào panel bị bỏ qua.
  - **Không e2e được phần thả**: macOS chỉ gửi đích thả cho source trong một phiên kéo chuột thật (thử `NSFilePromiseReceiver` đọc promise từ pasteboard ở process khác → chỉ gọi `fileNameForType`, không bao giờ gọi write), còn chuột giả CGEvent bị chặn khi terminal không có quyền Accessibility. e2e chỉ kiểm "bắt đầu kéo chưa tải gì"; thả vào Finder phải thử tay.
- **Tab bar**: các tab nằm trong `.tab-strip` (cuộn ngang, lăn chuột dọc cũng cuộn); nút ‹ › (`.tab-nav`) bên trái chỉ hiện khi tab tràn, mờ khi đã tới đầu/cuối, cuộn 70% bề rộng; nút + bên phải, cả hai nằm ngoài dải cuộn. Tab đang chọn tự cuộn vào tầm nhìn (tự tính `scrollLeft` kèm 12px đệm của dải — `scrollIntoView` không tính đệm nên tab cuối không tới được cuối). **Tab đang mở bao trùm terminal** (yêu cầu chủ dự án 2026-10-30): tab mở có viền 1px (`--frame-w`) trên/trái/phải, bo trên, nền `--bg`, chạm xuống khung `.tab-views` (viền cùng màu, bo 10px); tabbar `margin-bottom: -1px` + `z-index` để tab mở che cạnh trên của khung → mở thông vào terminal; hai góc lượn vào trong là `::before/::after` vẽ bằng `radial-gradient` (vòng `--frame`, ngoài vòng `--bg`). Màu viền `--frame` **trung tính** (pha `--fg` 18% vào `--bg2`) — chủ dự án chê viền màu session/accent gây mất tập trung (2026-10-30), nhận ra tab mở bằng hình dạng là đủ; không còn tab nào thì **màn hình chào chính là tab đang mở**: TabBar vẽ tab giả `.tab.active.welcome-tab` (icon home + "Welcome", không đóng/kéo/menu) để khung có tab treo vào; tab thật đầu tiên mở là nó tự biến mất. Màu session còn là thanh nhỏ `.tab-color` trên mọi tab. Tab không mở: không viền, chỉ là chữ trên nền cửa sổ (hover thành viên bo), thấp hơn để không chạm khung. Pin (`Tab.pinned`, chỉ trong RAM): luôn đứng đầu, gọn, không có nút đóng, middle-click không đóng; "Close others / to the left / to the right / all" (`closeTabsAround`) bỏ qua tab đã pin.
- Thanh stats: ô Disk hiện **mọi ổ của người dùng** (`splitDisks`: gần đầy nhất trước, tối đa 5 + "+N"), mỗi ổ mount + vạch + %; ổ hệ thống (`/boot`, `/boot/efi`, `/efi`, `/System/Volumes/*` trừ Data, và `/` của macOS khi có Data) chỉ nằm trong popup, mục "System". Script đọc `timeout 3 df -Pk` (có cả NFS/CIFS, không treo vì mount chết); máy không có `timeout` (macOS) thì `df -Pkl`. Container query: < 1000px còn 2 ổ, < 760px còn 1.
- **Bo góc** (2026-10-30): **một thang duy nhất, không viết px trực tiếp** — `--radius-lg` 14px (dialog, lock card), `--radius` 10px (panel, khung, tab, menu, popup, card, toast), `--radius-sm` 7px (nút, ô nhập, pane khi split, hộp nhỏ), `--radius-xs` 5px (dòng nằm trong container có đệm: dòng cây, mục menu, nút segmented = bán kính container trừ đệm để đường cong song song), `999px` (thanh mảnh/chip: meter, thanh màu, số đếm, badge); hình tròn giữ `50%`. Chú thích ở đầu styles.css. `--line` (đường kẻ mờ bên trong: header bảng, modal, stats…), `--panel` (nền sidebar). Sidebar và workspace là hai khối bo nằm trên nền `--bg2` của cửa sổ, cách nhau 6px — không dùng đường kẻ thẳng ngăn vùng. Split: `.tab-view.split` có nền `--bg2` + đệm 4px, mỗi pane bo góc, thanh chia trong suốt (hover mới hiện accent); pane đang chọn chỉ có header sáng hơn chút (không vạch accent). Multi-exec: nút ON là nền vàng nhạt + chữ vàng, pane nhận phím có viền vàng 1px mờ (không phải khối vàng / viền 2px). **Nguyên tắc: tinh tế, tránh màu loè loẹt.** Tab bên sidebar là segmented control.
- **Scrollbar** (styles.css, đầu file): `::-webkit-scrollbar` toàn app 10px, thumb dạng viên thuốc nổi giữa track trong suốt (viền trong suốt 3px + `background-clip: padding-box`), mờ 12% → 22% khi rê vào vùng cuộn → 36% khi rê lên thumb; không nút mũi tên, góc giao 2 thanh trong suốt. Áp cho cả `.xterm-viewport` (xterm 5.5 dùng scrollbar native). Lưu ý: đặt `scrollbar-width`/`scrollbar-color` trên phần tử nào thì Chromium bỏ qua `::-webkit-scrollbar` của phần tử đó (chỉ `.tab-strip` dùng `scrollbar-width: none`).
- **Tab có output ngầm**: output tới pane của tab không mở → `activity[tabId]` trong store (`noteActivity` trong terminals.ts) → class `activity` → tên tab "thở" chậm (`tab-breathe` 3.2s: muted → sáng + glow nhẹ, không nhấp nháy; `prefers-reduced-motion` thì chỉ sáng tĩnh). Mở tab là xoá. Không tính output do mình gây ra: `quiet(connId, ms)` sau khi gõ/multi-exec/macro gửi (1s), sau resize (1s), sau khi kết nối (2.5s, banner/prompt đầu).
- **Màu terminal tuỳ chỉnh** (Settings → Terminal): `termForeground` / `termBackground` / `termCursor` (#rrggbb, `''` = màu của theme). `termTheme(s)` trong themes.ts trộn lên `termThemes[theme]`; chỉ đổi màu mặc định, bảng 16 màu ANSI giữ nguyên (ls, prompt, vim vẫn màu của chúng). Mỗi ô: nút "Theme" + vài màu sẵn + ô cầu vồng (`<input type=color>`), có khung xem trước và cảnh báo khi tương phản < 3:1 (`contrast()`, WCAG). Nền tuỳ chỉnh còn đặt `--term-bg` inline trên `<html>` (App.tsx) để phần đệm của pane, khung `.tab-views` và tab đang mở (cả 2 góc lượn) cùng màu với terminal. e2e-ui kiểm bằng `webContents.capturePage().toBitmap()` (BGRA) đếm điểm ảnh màu chữ/nền — WebGL vẽ chữ trên canvas nên không đọc được từ DOM.
- Thứ tự macro = thứ tự mảng `macros` (số 1–9 trong picker, menu toolbar); đổi bằng kéo-thả hoặc ↑↓ trong Manage macros.
- Màu session: 7 màu sẵn + ô cầu vồng bọc `<input type=color>` (màu bất kỳ, lưu hex trong `session.color`).
- About/copyright chỉ hiển thị **một chỗ**: dòng mờ `v0.1.0 by Thao Pham` ở **màn hình chào**, giữa, ngay dưới hai nút (`AboutLine` className `welcome-about`, App.tsx; tên Nixi đã là tiêu đề ngay trên nên không lặp) — đã bỏ footer dưới đáy cửa sổ (2026-10-30), không đặt trong sidebar. Click → popup kiểu bảng disk (Version / Author (©) / Contact / Electron+Chromium+Node / System, mỗi thông tin **một lần**, lấy từ `app:info`), Esc hoặc click ra ngoài thì đóng. Hộp About native trong menu cũng chỉ còn copyright + email (credits), không lặp tác giả.
- Đổi master password (`changeMasterPassword` trong actions.ts): kiểm mật khẩu hiện tại **ngay** bằng `db:checkPassword` (sai → hỏi lại kèm hint, chưa hỏi mật khẩu mới); mật khẩu mới < 4 ký tự và nhập lại không khớp cũng hỏi lại tại chỗ thay vì báo lỗi ở cuối.
- SFTP panel không còn dòng hint "Drop files here…" ở đáy (chủ dự án muốn gọn).
- Tab SFTP ở sidebar chỉ hiện khi pane đang chọn là SSH (`activePaneOf(s)?.isSsh`); lựa chọn tab vẫn giữ trong store nên quay lại tab SSH thì SFTP hiện lại.
- Macro picker (`MacroPicker.tsx`, menu View → Run Macro at Cursor…). Phím do người dùng chọn: setting `macroPickerHotkey` (định dạng `hotkeyOf` — tên phím lấy theo `e.code` cho Space/dấu câu, vì `e.key` ra " " hoặc ký tự Option của mac; ⌘Space/⌃Space bị macOS giữ, không tới app; mặc định ⌘J / Ctrl+Shift+J), bắt ở keydown của renderer (App.tsx) như phím tắt macro; menu chỉ *hiển thị* phím (`registerAccelerator: false`, `toAccelerator()` trong shared/macro.ts) và được build lại khi đổi settings / macro / unlock. Phím người dùng chọn **thắng** phím tắt menu: `yieldToUserKeys` bỏ accelerator của mục menu trùng (cả role mặc định như ⌘Q, ⌘H qua `roleKeys`). Ô ghi phím (`HotkeyInput`) bật `hotkey:capture` → main bắt mọi tổ hợp trong `before-input-event` (trước menu) và gửi sang renderer. Playwright `keyboard.press` KHÔNG đi qua `before-input-event` — e2e dùng `webContents.sendInputEvent`. Picker đặt ngay dưới ô con trỏ (`cursorPoint` trong terminals.ts, tính cả khi đang cuộn lên), lật lên trên nếu thiếu chỗ. Số thứ tự = thứ tự trong danh sách macro. Input chỉ focus được sau khi popup hết `visibility: hidden` — đừng đổi lại thành `autoFocus`. Macro chạy được **ở mọi ô nhập text** (prompt mật khẩu, ô tìm kiếm, form…): `focusedField()` / `typeIntoField()` trong terminals.ts — gõ bằng `execCommand('insertText')` (React thấy, undo được), xuống dòng = Enter (chờ 1 tick cho React commit trước), bước "wait for output" bị bỏ qua; picker mở ngay dưới ô đó, Esc của picker `stopPropagation` để không đóng luôn dialog bên dưới. e2e có SSH phải ghi sẵn `known_hosts.json`, không thì hộp thoại native "Unknown host" treo test.

## Việc còn dở / chưa kiểm chứng
- Mac (2026-10-28, macOS 15.7 Intel): unit test, typecheck, e2e db/telnet/smoke/split/auth pass; `dist:mac` ra .dmg + .zip, bản đóng gói chạy được local zsh + SSH, Keychain (safeStorage) OK. - Chưa kiểm chứng: RDP đăng nhập thật có hình (chỉ test tới bước CredSSP), giải mã macro MobaXterm bằng master password thật, độ mượt RDP nhúng.
